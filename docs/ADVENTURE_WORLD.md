# 文印江湖：世界觀與遊戲規則

## 作品定位
《武俠打字傳》v2.0.0 正式預設首頁 `index.html`（同時保留 `adventure.html` 相容入口，原版修煉模式移至 `classic.html`）。沿用國風美術、注音引擎、官方字音與自編題庫，提供有結局的六章三十關故事。關卡資料唯一來源是 `src/data/adventureWorld.js`，此文件解釋設計，不另保存逐關副本。

## 世界與人物
青嵐書院以「以字為劍」為修行方法，守護記錄人們記憶的六枚文印。文印被帶走後，信件與書籍逐漸失去文字，人們忘記了姓名、承諾與共同經歷。

雲清川與蘇映雪是同行少俠，玩家選擇其中一人出戰。師父引導初學，信使維繫朋友，掌櫃保存旅人名冊，道童核對書信；刀客與護法會從對手轉為理解故事的同伴。

黑風寨主曾希望守護江湖，卻因誤解與失敗封閉自己，試圖以抹去文字逃避過去。最後的目標是打破封住記憶的黑風，讓他重新讀懂自己的文章，而非消滅一個人。

## 六章完整進程
| 章節 | 文印 | 故事功能 |
|---|---|---|
| 山門初行 | 勇氣 | 學會出招、送信下山、取得第一次試煉資格 |
| 竹海尋信 | 信任 | 找回名字與家書，理解巡山者的處境 |
| 古驛燈火 | 互助 | 修復旅人名冊、保護客棧，發現寨主往事 |
| 襄陽會武 | 堅毅 | 公平切磋、找到節奏，取得月下書院線索 |
| 月下墨閣 | 明辨 | 拼回完整文章，釐清造成隔閡的誤解 |
| 雲海歸字 | 傳承 | 帶著朋友回信登山，六印重聚，完整結局 |

每章五關，包括練功、旅程、委託、一般交手與首領切磋；第三章以客棧事件串起故事。所有主線關卡都需完成十題實際輸入。非戰鬥事件不回擊；首領依完成題數分試探、破防、決勝三階段。

## 操作與成長
- 首次只選年級／英文與角色，之後首頁直接「繼續冒險」。Enter 開始、接續與過關，Tab 開關鍵盤，Esc 開設定。
- 1～6 年級與英文各自保存主線與逐音進度；財產及人物共用。三大境界可在設定調整，不另外強迫重跑三十關。
- 年級沿用既有單字／短詞／長句比例。近期題目避重，弱點題以同長度類型替換回流，不破壞十題配額；題庫不足時仍保留正確比例。
- 每題完成獲得一點內力，上限五點。Alt＋1 施放守護劍陣：對手停招八秒，再抵擋一次回擊；不代打或跳題。
- 普通關三十銅錢，首領六十銅錢；青鋒收益加成 25%，玄鐵 50%，同時更換人物服裝與劍光。價格沿用原有 150／360 銅錢。
- 每日首次完成加二十銅錢，缺席不扣獎勵或重置主線。結算呈現真實題數、字數、正確率、連擊、文印與下一站。
- 失敗不領銅錢，完成題數與目前字音保留；調息恢復氣血並放慢下一段回擊。完成主線後開啟三十關重遊。

## 兒童保護與時間規則
按錯不直接扣血、免退格。連錯兩次突出同一提示區並放慢回擊。每個新題有四秒閱讀寬限；首次作答前不蓄力；回擊時間依題目長度與年級增加。選單與背景頁面暫停交手及打字計時。

## 相容性與範圍
新版使用 `wuxia_adventure_v1`。首次從原版存檔單向複製角色、銅錢、已購裝備，不寫回原版或推定舊關卡屬於新版故事。原圖不修改，完整字典仍延遲查詢。字音與例詞依教育部國語小字典；練習分級、故事與散文為遊戲自編，並非出版社完整課本。

本版是可完整通關的冒險試玩版。沿用現有靜態立繪與動態劍光；尚無人物配音、逐格跑步動畫、多人連線或雲端存檔。遊戲是否更有吸引力與學習成效仍需真實學童試玩。
