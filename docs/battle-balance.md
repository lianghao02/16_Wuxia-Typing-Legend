# 戰鬥節奏診斷（隔離模擬）

## 範圍與限制
基準為 `feat/jianghu-adventure`／`a6b63e5` 加上目前未提交修正。執行 `npm run diagnose:balance`；需要逐筆資料時執行 `node scripts/analyze-battle-balance.mjs --json`。

共 1,512 組：七種題本 × 三境界 × 三關（第 1、5、30 關）× 三套裝備 × 每秒 2／5 次按鍵 × 不施放／滿氣立即施放絕招 × 零錯鍵／每十鍵錯一鍵。固定亂數，前十題相同；動態補題沿用正式抽樣器。

使用正式 `TypingEngine`、事件處理器、傷害、敵人 `tick`、丹藥與絕招函式，替換 DOM、音效、儲存及時鐘，不接觸玩家存檔。時間以 50ms 步進，第一次輸入等待 700ms；一旦需要調息即停止，十分鐘為模擬上限。沒有模擬閱讀、找鍵、IME、網路、真人猶豫、後續調息保護與主線購裝過程；WPM 不取用實體時鐘資料。

「新手／中階／高階」分別使用木劍＋布衣＋粗布護腕、青鋒劍＋百草袍＋流雲護腕、六階槍＋赤鱗鎧＋宗師護腕。三套裝備都保留預設一份回春丹及清心散；高階裝備直接帶進早期關卡是假設邊界，不代表正常養成路線。

## 問題、處置與下一輪

| 問題／觀察 | 處置與驗收 |
|---|---|
| 絕招結束未完成題目時，結算原本至少顯示完成一題 | 已修：完成幾題就顯示幾題；0 題也如實記錄，不補寫學習歷史。正式處理器回歸測試通過 |
| 定身以實體時間計時，開選單或切走分頁會耗掉剩餘秒數 | 已修：改用有效戰鬥時間；選單、分頁隱藏、失焦各停留 20 秒後，剩餘定身不減少；回戰鬥後可正常到期 |
| 英文字母連擊與中文字連擊的輸入成本不同 | 待調整：先比較完整英文單字、中文單字與長句的集氣成本，再決定獎勵以字元、完整單字或有效按鍵量計算；不先增加另一套技能選單 |
| 高階裝備大幅提高容錯與縮短早期關卡 | 待實玩：區分原年級重遊與切換新年級；先看是否削減必要練習量，再考慮對新題本設定練習目標，不直接取消裝備成長感 |
| 宗師境界對固定錯鍵較敏感，新手裝備 19／84 組需調息 | 待實玩：檢視是哪個年級、句長與施招策略，再調蓄力、錯鍵保護或補給；不要一律提高氣血 |
| 同一關跨年級練習量差異明顯 | 以完成字數、有效按鍵量、時間與調息次數一起評估；不能只比較題數，也不直接恢復固定十題制 |
| 人物與鍵盤是否遮擋、字級是否可讀 | 本模擬沒有畫面；仍待 Browser 跨尺寸、縮放與攻擊峰值實測 |

第一輪未改傷害曲線、敵人血量、裝備價格或連擊獎勵。下節記錄第二輪已實作的規則；前述結果保留為比較基準。


## 第二輪修訂與複驗

- **英文獎勵成本**：四個英文字元算一個連擊獎勵單位，純英文於 20／40／60 字元發獎；輸入判定、畫面字母連擊與既有傷害曲線不變。中英混合累加加權進度，切換語言不灌滿內力；失誤保留連擊時也按比例保留獎勵進度。
- **先破防、再收招**：每關至少完成 24 次正確按鍵，且必須完整完成目前題目。太早的致命攻擊保留敵人 1 HP，絕招仍提供傷害、護印與定身。關卡標題列顯示「已破防・正確按鍵 X／24」或「完成本題收招」，不新增操作或設定。錯鍵不計入門檻；進度隨原續玩存檔保存。24 是集中設定的開發候選值，仍待真人驗證。
- **裝備保留差異**：未改武器傷害公式、敵人血量、價格、回血、防禦或收益；基本練習量之後仍以實際 HP 勝負。

第二輪全部 1,512 組完成診斷，所有通關案例均滿足至少 24 正確按鍵及至少完成一題；腳本內含門檻斷言。零錯鍵 756 組中 755 組通關、1 組需調息：英文宗師第 30 關、木劍、每秒兩鍵且不施放絕招，75.5 秒時尚餘敵人 37 HP。這是低速、低裝備與不用技能的邊界，不以全面降低難度來追求全數通關。每十鍵錯一鍵的新手／中階裝備需調息數，初階 4／2、中階 7／4、宗師 20／11（各 84 組）；高階均為 0。

測試 80／80 通過，包含英文獎勵不重複、中英切換、破防時續玩、錯鍵不湊練習量及完整收招。仍未取得新 Browser 畫面證據，不宣稱教學難度已驗收或畫面零遮擋。
